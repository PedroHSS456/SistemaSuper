# Yoru Launcher

Launcher Android leve, visual cozy lo-fi com clima de Japao noturno, pensado para o Moto E7 Plus.

- Nao substitui nem altera nada do Android. E um app comum.
- So vira a tela inicial se voce escolher; para voltar, escolha o launcher antigo nas configuracoes.
- O app **Yoru Launcher** aparece na lista de apps (e a tela de personalizacao) e pode ser desinstalado normalmente.
- Sem bibliotecas externas, sem servicos em segundo plano. A animacao so roda com a tela inicial visivel.

## Baixar

Aba **Releases** do repositorio, arquivo `Yoru-Launcher.apk`. Cada alteracao no repositorio gera uma versao nova automaticamente.

## Wallpapers animados

- Pelo celular: abra **Yoru Launcher**, **Escolher da galeria**, e selecione um GIF, MP4/WebM ou imagem.
- Pelo repositorio: coloque os arquivos em `app/src/main/assets/wallpapers/` e eles viram opcoes dentro do app.
